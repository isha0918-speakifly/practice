# Speakifly - Speaking Practice Web App

Upload all files to a GitHub repo, then Settings > Pages > Deploy from branch (main / root). Open the https link (microphone needs https).

- Replace `logo.png` to change the logo
- Edit sentences / word meanings (English, Hindi, Gujarati) in `sentences.js`; use {N} where the student's name should appear
- `DAILY`, `DAYS`, `QUIZ_EVERY` are at the top of `app.js`
